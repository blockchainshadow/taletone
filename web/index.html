第一次使用？三步开始 可随时展开
  1. 打开视频

    选择本机视频，只在此浏览器读取。推荐 MP4（H.264 / AAC）或浏览器支持的 WebM。

  2. 加入熟悉的声音

    导入本地应用生成或自己录制的音频，为它命名。支持多条语言配音，必要时微调时间偏移。

  3. 切换、试听、保存

    点声音卡片后播放。外部配音期间原声始终静音；导出 JSON 保存设置，下次重新关联媒体文件。

你想听哪一种？

共享视频进度，切换声音不从头开始。

添加已有配音

支持浏览器可解码的 MP3、WAV、M4A，以及已有配音 MP4 的声音。不上传媒体，不会翻译、克隆声音或生成音频。

当前配音设置

正数：延后配音；负数：跳过配音开头。配音结束后画面继续，保持静音，绝不切回原声。

项目 JSON 保存了什么？

保存项目名称、媒体文件名 / 大小 / 修改时间、声音名称、时间偏移、所选声音、观看进度和倍速；不包含视频或音频文件，也不导出配好音的视频。导入后必须手动重新选择本机视频与每条音频。浏览器不能根据文件名恢复文件内容。重新关联会使用你实际选择的文件，请自行确认是正确素材。

此页面不自动保存媒体或项目。关闭或刷新前，请导出 JSON；原始媒体文件不会被修改。导出的 JSON 含文件名，请在分享前检查。
